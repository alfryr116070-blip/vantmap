# Code of Conduct

We follow the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, welcome newcomers, critique claims and code — not people. Harassment, personal attacks
and publishing others' private information are not tolerated. Companies and teams listed in the maps may file
corrections like anyone else; they get no special treatment and no worse treatment.

Report problems privately to the repository owner through GitHub's "Report a vulnerability" / private security advisory form on the repository (Security tab), or by opening an issue if it doesn't need to be private.
Maintainers may remove content and block accounts that break these rules.
